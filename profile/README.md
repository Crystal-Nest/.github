# Crystal Nest

## About Crystal Nest

Crystal Nest is a Minecraft modding project created and maintained by me, Riccardo (Crystal Spider).  
It all started with a mod I made for a private Minecraft server. Over time, that small project grew into a collection of mods, tools, and resources that I continue to develop and maintain independently.  
I take care of development, releases, documentation, and user support, with the goal of creating useful, well-structured projects that people can enjoy.

## Projects

Crystal Nest includes a growing collection of Minecraft mods, alongside open-source tools and templates for other developers.  
My mods have reached over 100 million downloads in total, something I never imagined when I first started!

I try to support multiple Minecraft versions whenever possible, although the exact versions depend on each project. You can find up-to-date compatibility information on the respective mod pages.  
There are still plenty of ideas I'd like to explore, from improvements to existing mods to entirely new projects. I hope you look forward to it as much as I do!

## Useful resources

You can find all my mods and other resources on the [Crystal Nest website](https://crystalnest.it), including an up-to-date, customizable template for multiloader Minecraft mods.  
Some projects also have their own documentation and wikis, available through their GitHub repositories.
